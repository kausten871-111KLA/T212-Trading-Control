Audit the current state before changing anything.

Then:
1. identify defects, gaps, duplicates, stale assumptions and hidden blockers;
2. separate verified facts from inference;
3. make only bounded, justified changes if authorised;
4. re-read the affected state after each material change;
5. report VERIFIED / FAILED with brief evidence.

Do not claim completion from a prior pasted report alone. Treat live state as the acceptance test.
