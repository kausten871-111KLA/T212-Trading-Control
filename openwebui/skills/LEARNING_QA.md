# Learning & QA

## Purpose
Make the system improve from both executed and missed opportunities.

## Required review
- proposal versus actual broker fill;
- entry timing;
- exit timing;
- realised P/L;
- whether the original catalyst thesis remained valid;
- false positives;
- late entries;
- stale or missing data;
- execution/tool failures;
- missed greens and why no entry occurred;
- benchmark behaviour against recognised day-trading practitioners without blindly copying signals.

## Benchmark set
Use as process/discipline reference points, not as unquestioned signal sources:
- Ross Cameron
- SMB Capital / Mike Bellafiore
- Steven Dux
- Andrew Aziz
- TraderTV Live
- Humbled Trader
- Timothy Sykes
- Jack Kellogg

## Output
- what happened
- why it happened
- what the system did
- whether the process was correct
- missed-opportunity reason if applicable
- one concrete rule/process improvement
- evidence
