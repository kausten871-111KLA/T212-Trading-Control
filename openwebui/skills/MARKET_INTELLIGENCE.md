# Market Intelligence

## Purpose
Discover and explain actionable DEMO opportunities.

## Required work
- scan greens / movers / unusual volume / momentum;
- identify catalysts and explain cause -> financial impact -> price response;
- distinguish early move, established move, extended move and reversal risk;
- check liquidity, spread, volatility and obvious manipulation/dilution risk where relevant;
- use fresh sources and current market state;
- resolve the ordinary symbol/company to the exact T212 instrument before execution handoff.

## Output
- instrument/company
- ordinary ticker
- exact T212 ticker if resolved
- current move
- catalyst / cause-effect explanation
- liquidity / spread / volatility note
- timing state
- source/evidence
- handoff: WATCH / QUALIFY / REJECT

Never place broker orders.
