# Learning & QA

Review proposal versus actual broker fill, entry/exit timing, realised result, catalyst validity, false positives, late entries, stale/missing data, execution/tool failures and missed greens.

Use recognised traders only as process/discipline benchmarks, not copy-trade authorities: Ross Cameron; SMB Capital / Mike Bellafiore; Steven Dux; Andrew Aziz; TraderTV Live; Humbled Trader; Timothy Sykes; Jack Kellogg.

Output what happened, why, what the system did, whether process was correct, missed-opportunity reason, one concrete improvement and evidence.
